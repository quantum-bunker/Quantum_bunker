# Search Messages

## Definition
A real-time text filter that narrows messages in the current chat room to only those containing the entered keyword.

## Purpose
To locate a specific message within the chat history of the current session without scrolling.

## Access
Left sidebar of the chat room, under the "Search Messages" heading. Visible to both host and member roles.

## Usage Steps
1. While in a chat room, locate the "Search Messages" panel in the left sidebar.
2. Click the text field labeled "FILTER_BY_KEYWORD" and type a word or phrase.
3. The message list immediately filters to show only messages containing the entered text.
4. Matching text within each message is highlighted in amber.
5. To reset, click the X button that appears inside the search field, or clear all entered text.

## Options/Settings
None.

## Result
- Only messages with content matching the keyword remain visible.
- Matched text is highlighted with an amber background.
- If no messages match, the message area shows "No messages match" followed by the search term.
- Clearing the search query restores the full message list.

## Notes/Limitations
- Search is local and real-time with no submit button or delay.
- Search applies to message body text only.
- The search is case-insensitive after normalization.
